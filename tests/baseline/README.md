# Visual regression baseline

Эталонные PNG страниц сгенерированных DOCX. Лежат в `png/<scenario>/p01.png …`.
DOCX-файлы в `docx/` НЕ коммитятся — это рантайм-артефакты, см. `.gitignore`.

## Когда обновлять

Только при намеренном изменении вывода:
- новые/удалённые плейсхолдеры
- правка `templates/kp_template.docx`
- изменение порядка / форматирования спецификации
- правки `payment_renderer.py` или `kp_generator.py`, влияющие на текст

## Как обновить

```
pytest -m e2e tests/e2e --update-baseline
```

После запуска проверь `git diff -- tests/baseline/png/` глазами:
изменения должны соответствовать тому, что ты сознательно поправил.

## Почему именно PNG, а не DOCX

DOCX — ZIP с XML внутри, diff бесполезен и шумит на каждой регенерации
(меняются ID и таймстемпы). PNG читается на ревью буквально глазами.
DOCX генерируется заново на каждый запуск тестов — он не нужен в репо.

## Почему через LibreOffice

Кроссплатформенно, бесплатно, headless. Word COM требует лицензию и
нестабилен. На Windows установить LibreOffice + добавить poppler-windows
в PATH (см. корневой README).
