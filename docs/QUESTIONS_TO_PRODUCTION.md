## 🟡 Расхождения с реальными КП (ожидаемые)

Найдены при сверке JSON с двумя твоими КП (Гипсобетон, Кирова):

### 1. Толщина настила
- **По справочнику (JSON-дефолт):** С-80 = 8 мм, ФЛ-80 = 6 мм
- **В КП Гипсобетон (С-80):** 10 мм
- **В КП Кирова (ФЛ-80):** 8 мм

**Статус:** это не баг. Ты сам подтвердил — настил ставится по запросу
клиента. В конфигураторе будет дефолт из справочника + редактируемое поле.

### 2. Температурный диапазон индикатора
- **По описанию типа (JSON-дефолт):** –10…+40 °C (ТИТАН 3ЦС)
- **В твоих КП:** 0…+40 °C

**Статус:** тут расхождение с документом утверждения типа.
Нужно понять, где правда.
- Если ТИТАН 3ЦС действительно –10…+40 → в КП у менеджера ошибка, нужно чинить шаблон.
- Если в КП правильно 0…+40 → значит описание типа или устарело, или в твоей компании для КП принята более консервативная цифра (например, гарантия работы).

**Действие:** уточнить с производством/метрологом, какая цифра корректна
для КП и почему она отличается от описания типа.

### 3. Гарантия
- **JSON-дефолт:** С/Ф = 36 мес., СЛ/ФЛ = 24 мес., П = 36 мес. (предположение)
- **Твоё правило:** для Сибири и тяжёлых условий — снижаем до 24 мес. даже для С/Ф

**Статус:** в конфигураторе гарантия будет редактируемым полем с дефолтом
по линейке. Менеджер сможет снизить. Для MVP — окей.

**Уточнить:** какая гарантия штатно для линейки П? (пока поставил 36 по умолчанию)
