# Аудит комбинаторики clauses — 2026-06-10

Аудит комбинаторики clauses (data/clauses.yaml)
 Только анализ. Правок нет. Сверено с реальным кодом: src/contracts/clauses_dsl.py, clauses_context.py, clauses_renderer.py (build_contract_clauses), clauses_loader.py, spec_v2_filler.py, UI
 src/pages/2_Договор.py, маппинг items from_kp.py, шаблон templates/contracts/spec_v2.docx.

 Контекст

 clauses.yaml содержит 23 пункта в 4 секциях. build_contract_clauses(deal) фильтрует по DSL-условиям, нумерует сквозно с 4, считает obligations_range, подставляет jinja-параметры. Секции с нулём пунктов
 просто не попадают в результат; в DOCX-шаблоне заголовков секций нет — маркеры {{CLAUSE_SECTION_*}} удаляются бесследно, «висячих заголовков» не бывает. Зато бывает договор, где обязательства сторон
 отсутствуют целиком, и битый текст в «Заключительных».

 Факты о достижимости (из кода, не предположения)

 - Items побеждают overrides. В clauses_context.py override применяется только если соответствующего item НЕТ (if "foundation" in items_by_id: ... elif overrides...). UI же подаёт expander как «вручную
 переопределить» — менеджер выбирает «Заказчик строит» при наличии позиции фундамента, и выбор молча игнорируется.
 - Скрытый 6-й scope contractor_supervised. Item foundation_supervision («Курирование строительства фундамента») маппится в contractor_supervised, которого нет ни в шапке-DSL clauses.yaml, ни в одном
 applies_when, ни в override-опциях UI. Ведёт себя как none.
 - customer_builds достижим ТОЛЬКО через override — ни один item-ключ в него не маппится.
 - has_orion определяется только наличием item orion — override отсутствует. orion_poles_scope=by_contractor — из item orion_install либо override.
 - Зимний чекбокс в UI не гейтится по foundation_scope; ставит winter_surcharge = winter_concrete = checkbox.
 - Валидации сочетаний scope нет вообще. Кнопка генерации проверяет только requisites/specification/номер/адрес. Паттерн (errors, warnings) на договорную страницу не распространён.
 - Jinja-рендер с jinja2.Undefined (не Strict) — любой неизвестный плейсхолдер молча превращается в пустую строку.
