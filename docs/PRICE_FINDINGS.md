# Находки из прайсов — что оказалось неожиданным

Источники: `2026.03.01 Прайс розница Tenzosila.pdf` и `2026.03.01 Прайс дилер+экспорт.pdf`.  
Дата разбора: 2026-04-23.

## Ключевые находки

### 1. Линейка П — только 100 тонн
В прайсе ВЕСТА-П представлена **только в Max=100т**, длины 18/20/22/24м.
В `build_models.py` были заведены заглушки для 40/60/80т — они удалены.
Итого П: 4 модели вместо 16.

### 2. ВЕСТА-С-120-24 — есть в прайсе
Неожиданно: в розничном прайсе есть строка «120 тонн / 24м / С» с ценой 3 316 202 руб.
Добавлена в scope как единственная модель 120т. Масса/профиль/настил — нет данных.

### 3. 40-тонные модели отсутствуют в прайсе
В розничном и дилерском прайсах нет ни одной позиции для Max=40т.
Итого: 40т-модели (16 штук в models.json) не включены в prices.json.

### 4. Для 20м: два варианта — 3-секц. и 4-секц.
Для длины 20м в прайсе присутствуют ДВА ценника (3-секционный и 4-секционный).
Для scope MVP взят **4-секционный** (он же стандартный для 20м согласно справочнику).
Пример: ВЕСТА-С-80-20 3-секц = 2 392 014, 4-секц = 2 446 378 руб.

### 5. Пять пресетов ПАК ОРИОН
Оказалось 5 пакетов вместо ожидаемых 2–3:
Лайт / Стандарт / Стандарт+ / Автоматика / Автоматика+.
Диапазон цен: оборудование 135–739 тыс. руб., монтаж 110–195 тыс. руб.

### 6. Скидки в дилерском прайсе
Для автовесов ВЕСТА и большинства опций скидка одинакова: **8%** (dealer_ru = retail × 0.92).
Дилер ЕАЭС рассчитывается от дилерской РФ-цены: dealer_eaes = dealer_ru / 1.20 (НДС 0%).
Для ПАК ОРИОН и некоторых аксессуаров скидка иная: 9%, 10%, 12%, 18% — для других категорий (РЕУС, ВЕКТОР, животноводческие), не в нашем scope.

### 7. Доставка и поверка — не фиксированы
В прайсе нет фиксированных позиций «доставка» и «поверка».
Зафиксированы в `options.json` как `is_negotiable: true` с примечаниями.

### 8. СЛ-100 и ФЛ-100 отсутствуют в прайсе
Модели с Max=100т для облегчённых линеек СЛ и ФЛ в прайсе не представлены.
В `models.json` они есть (из справочника), но в `prices.json` не включены.

## Обновление v0.2 (2026-04-23)

**ЕАЭС-цены убраны из scope MVP.** Формула `dealer_eaes = dealer_ru / 1.20`
была выведена эмпирически из одной строки прайса и не провалидирована по
всем позициям. Менеджер принял решение работать только с розницей и дилером
РФ. ЕАЭС вернём отдельной задачей с выверенными цифрами, если понадобится.
