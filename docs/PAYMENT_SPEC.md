## Формула строки КП

```
— <Название> <%> <база> <предлог> <событие> (<N> дней).
```

**Названия:** Предоплата / Доплата / **Оплата** (только когда платёж единственный — правило W3).
«Перед отгрузкой» — НЕ название платежа, это момент. Использовать «Доплата».

**База — в КАЖДОЙ строке, без исключений.** Строка читается самостоятельно.
Не «Доплата 50%», а «Доплата 50% общей стоимости».
Термин «проект» НЕ использовать — его нет в договоре.

**Предлоги единообразны:** «при подписании» / «по готовности» / «по Акту».
Не смешивать с «после», «по факту», «с момента».

**Срок — в скобках, `(N дней)`.** Любое N от 1 до 30; согласование даёт `due_days_phrase`.

**Монтаж и поверка — одной сдвоенной строкой** (компактность важнее симметрии с Договором).

**Шеф-монтаж ПАК ОРИОН растворяется в «монтажных работах»**, если монтаж весов есть
(правило поглощения B11, эталон Горняка). Отдельно называется только когда монтажа весов нет.

**Порядок строк — хронология сделки:**
подписание Договора → Акт фундамента → готовность к отгрузке → готовность к монтажу → Акт работ.
**Фундамент раньше отгрузки.**

**Регистр строчный**, кроме «Акт» и «Договор».

**Сноска под блоком:** *Сроки указаны в банковских днях.*

---

## Инвариант КП ↔ Спецификация

Множество платежей и их порядок — **одинаковы**. Отличие одно: КП сдваивает
монтаж и поверку в одну строку, Спецификация печатает их двумя пунктами.
Клиент сверяет документы построчно — расхождений быть не должно.

Спецификация уже в хронологическом порядке — **правим КП, не Спецификацию.**

## Формы

### 1. split — весы + фундамент + монтаж + поверка + доставка
```
— Предоплата 50% стоимости весов и фундамента при подписании Договора (5 дней).
— Доплата 50% стоимости фундамента по Акту строительства фундамента (5 дней).
— Доплата 50% стоимости весов и доставки по готовности весов к отгрузке (5 дней).
— Монтаж и поверка: предоплата 50% по готовности к монтажу, доплата 50% по Акту выполненных работ (5 дней).

Сроки указаны в банковских днях.
```

### 2. prepay_100 — 100% предоплата

Сроки указаны в банковских днях.

### 3. v1 — аванс + постоплата
```
— Предоплата 50% общей стоимости при подписании Договора (5 дней).
— Доплата 50% общей стоимости по Акту выполненных работ (5 дней).

Сроки указаны в банковских днях.
```

### 4. v2 — аванс + перед отгрузкой + постоплата
```
— Предоплата 30% общей стоимости при подписании Договора (5 дней).
— Доплата 40% общей стоимости по готовности весов к отгрузке (5 дней).
— Доплата 30% общей стоимости по Акту выполненных работ (5 дней).

Сроки указаны в банковских днях.
```
⚠️ «Перед отгрузкой» убрано из названий. База добавлена (её не было вовсе).

### 5. v3 — 100% постоплата
```
— Оплата 100% общей стоимости по Акту выполненных работ (5 дней).

Сроки указаны в банковских днях.
```
Точка отсчёта выбирается менеджером: «по поставке весов» / «по завершении
монтажа» (дефолт) / «по Акту выполненных работ» (реш. Антона 2026-07-14).

### 6. split — весы без опций (поставка)
```
— Предоплата 50% стоимости весов при подписании Договора (5 дней).
— Доплата 50% стоимости весов по готовности весов к отгрузке (5 дней).

Сроки указаны в банковских днях.
```
Термин «проект» не используется (его нет в договоре) — база «стоимости весов».

### 7. split — весы + монтаж (без фундамента)
```
— Предоплата 50% стоимости весов при подписании Договора (5 дней).
— Доплата 50% стоимости весов по готовности весов к отгрузке (5 дней).
— Монтаж и поверка: предоплата 50% по готовности к монтажу, доплата 50% по Акту выполненных работ (5 дней).

Сроки указаны в банковских днях.
```

### 8. split — весы + рама + пандусы (поставка, без монтажа)
```
— Предоплата 50% стоимости весов, комплекта пандусов и рамы при подписании Договора (5 дней).
— Доплата 50% стоимости весов, комплекта пандусов и рамы по готовности весов к отгрузке (5 дней).

Сроки указаны в банковских днях.
```
Порядок «комплекта пандусов и рамы» — как в Спецификации (инвариант КП↔Спец;
обратный порядок в ранней редакции этой формы был опечаткой, реш. Антона 2026-07-14).

### 9. split — весы + ПАК ОРИОН + опоры
```
— Предоплата 50% стоимости весов (включая ПАК ОРИОН) и фундамента при подписании Договора (5 дней).
— Доплата 50% стоимости фундамента и установки опор и кабель-трасс для ПАК ОРИОН по Акту строительства фундамента и установки опор (5 дней).
— Доплата 50% стоимости весов (включая ПАК ОРИОН) по готовности весов к отгрузке (5 дней).
— Монтаж и поверка: предоплата 50% по готовности к монтажу, доплата 50% по Акту выполненных работ (5 дней).

Сроки указаны в банковских днях.
```
⚠️ Шеф-монтаж ОРИОНа **не называется** — растворён в «монтажных работах» (монтаж весов есть).
⚠️ Падеж родительный: «и установк**и** опор» — в обоих регистрах (после «стоимости»).

### 10. Класс «монтаж без поверки» (G-10, после B11)
```
— Монтаж: предоплата 50% по готовности к монтажу, доплата 50% по Акту выполненных работ (5 дней).
```
Композиция даёт «монтажных работ» без поверки — уже реализовано B11, здесь только фиксируем норму.

### 11. Класс «шеф-монтаж ПАК ОРИОН без монтажа весов»
```
— Шеф-монтаж ПАК ОРИОН: предоплата 50% по готовности к монтажу, доплата 50% по Акту выполненных работ (5 дней).
```
Поглощения нет — монтажа весов нет, ОРИОН называется прямо.

## Решения по бывшим открытым вопросам (Антон, 2026-07-14)

1. Форма 1, строка 1: смешанная база «стоимости весов и фундамента» —
   **оставлена** (совпадает со Спецификацией, п.2.1).
2. Формы 10–11: сдвоенная строка монтаж/поверка — **уместна**, как в форме 1
   (реализовано, см. MATRIX формы 7/9/11).
3. «Производство начинается после поступления оплаты» в `prepay_100` —
   **удалена целиком**, никуда не переносится.
4. v3-триггеры: «по поставке весов» / «по завершении монтажа» /
   «по Акту выполненных работ» («после …» запрещено эталоном).
5. Форма 8: порядок «комплекта пандусов и рамы» — ранняя редакция формы
   содержала опечатку, норма выровнена по Спецификации.
