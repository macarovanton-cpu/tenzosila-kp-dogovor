# Бэклог идей и фич

Всё, что «не сейчас, но стоит помнить». Перемещается в работу по мере
готовности фазы.

## Фаза 2+
- Генерация договоров из утверждённого КП
- Сохранение истории КП с поиском
- Укороченный шаблон КП для повторных клиентов (2–3 стр.)

## Фаза 3+
- Интеграция с Битрикс (подтяг номеров лидов, реквизитов)
- Расширение на другие продуктовые линейки (индикаторы, вагонные весы)
- Раскатывание на команду менеджеров: разграничение прав, общая БД

## Мелочи
- Валидация: если гарантия ниже дефолта линейки — запрашивать комментарий
- Подсказки при заполнении: «эта модель обычно идёт с такой комплектацией»
- В колейных КП (Ф/ФЛ) поменять блок «Преимущества модулей ВЕСТА-С»
  на соответствующий линейке (или общий)
