# Лог ключевых технических решений

Формат: дата, решение, причина.

## 2026-04-XX: Справочники в JSON, а не в SQLite/CSV

Причина: MVP, одна точка правды, легко редактировать руками, легко версионировать
через git. SQLite — избыточно на этом этапе, CSV — плохо работает с вложенными
структурами (axle_loads, line_defaults).

## 2026-04-XX: python-docx для генерации DOCX

Причина: стандарт индустрии, достаточно функционала для шаблонной подстановки.
Альтернативы (docxtpl) избыточны для первого шаблона; при необходимости
мигрируем позже.
