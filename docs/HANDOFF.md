## 3. Файлы для Knowledge нового проекта Claude

Прикрепить в новом проекте следующие файлы из репо
(claude.ai → проект → Project knowledge → Add):

- `docs/STATUS.md` — текущая фаза, баги, что делаем дальше
- `docs/ROADMAP_ETAP_3.md` — план Этапа 3 (реестр шаблонов, конструктор оплаты, приложения)
- `docs/session_state_audit.md` — аудит session_state
- `data/options.json` — справочник опций (фундаменты, ПАК ОРИОН)
- `data/payment_terms.json` — пресеты оплаты

При обновлении этих файлов в репо — заменить старые версии
в Knowledge проекта Claude (Knowledge не подхватывает изменения
из репо автоматически).

## 6. Правила обновления HANDOFF.md

Обновлять при:
- смене крупной фазы (например, после закрытия Этапа 3)
- изменении системной инструкции
- изменении User Preferences
- изменении списка файлов для knowledge

НЕ обновлять при:
- закрытии отдельной итерации (это в STATUS.md)
- закрытии бага (это в STATUS.md)
- завершении промта в Code (это в STATUS.md)

При обновлении — закоммитить отдельным коммитом с префиксом `docs(handoff):`.
