# Конвертация PDF-чертежей фундаментов в DOCX

Скрипт:

```text
scripts/pdf_to_fundament_docx.py
```

Назначение: из PDF-чертежа фундамента создать DOCX-приложение к спецификации в формате шаблона:

```text
templates/contracts/spec_v2.docx
```

Скрипт сохраняет оформление приложения: шапку, параметры страницы, стили, чертёж на странице и блок согласования «Утверждаю».

## Подготовка

PDF-чертежи фундаментов нужно положить в папку:

```text
data/fundament/pdf_source/
```

Если есть контрольные листы, их можно положить в подпапку:

```text
data/fundament/pdf_source/control_sheet/
```

## Конвертация одного PDF

Пример команды:

```powershell
python scripts/pdf_to_fundament_docx.py "data/fundament/pdf_source/ИМЯ_ФАЙЛА.PDF"
```

Результат будет создан в папке:

```text
data/fundament/build_task/
```

Например, если исходный файл называется:

```text
data/fundament/pdf_source/пандусный_С_Ф_3 скц.PDF
```

то результат будет создан как:

```text
data/fundament/build_task/пандусный_С_Ф_3 скц.docx
```

## Пакетная конвертация всех PDF

Чтобы обработать все PDF из папки `data/fundament/pdf_source/`, нужно выполнить:

```powershell
python scripts/pdf_to_fundament_docx.py --all
```

Скрипт обработает файлы:

```text
data/fundament/pdf_source/*.pdf
data/fundament/pdf_source/*.PDF
```

Если существует папка:

```text
data/fundament/pdf_source/control_sheet/
```

то PDF из неё будут обработаны отдельно.

## Где искать результат

Обычные приложения создаются в папке:

```text
data/fundament/build_task/
```

Контрольные листы создаются в папке:

```text
data/fundament/control_sheet/
```

## Что проверить после генерации

После генерации нужно открыть DOCX в Microsoft Word и проверить:

1. Шапка приложения отображается корректно.
2. Чертёж помещается на страницу и не выходит за поля.
3. Блок «Утверждаю» расположен корректно.
4. Если PDF многостраничный, каждая страница PDF перенесена на отдельную страницу DOCX.
5. Плейсхолдеры вида `{{ДОГОВОР_НОМЕР}}`, `{{ДОГОВОР_ДАТА_ПОЛНАЯ}}`, `{{ЗАКАЗЧИК_ДИРЕКТОР_ИНИЦИАЛЫ}}` сохранились.
6. DOCX можно дальше использовать в процессе генерации договора через шаблонизацию.

## Тесты


```powershell
pytest tests/ -v
```

## Важные ограничения

Скрипт рассчитан прежде всего на PDF-чертежи формата A3 в горизонтальной ориентации.

Если PDF имеет нестандартную ориентацию или отличается по пропорциям, скрипт масштабирует изображение так, чтобы оно не выходило за доступную область страницы DOCX.

Реальные PDF-чертежи и сгенерированные DOCX не должны коммититься в git. Они используются как локальные рабочие данные.
