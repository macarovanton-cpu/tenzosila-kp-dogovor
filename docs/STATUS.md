## Известные ограничения (не баги — принятый MVP-скоуп)

- `named_form`/`ИМЕНУЕМ`: Колхоз/Компания/Фирма → «именуемое» (не всегда грамматически точно).
- Между двумя таблицами docx нужен ≥1 абзац-разделитель.
- ОРИОН-приложения (Шаг 10) — не реализованы как пакет документов.
- Контрольный лист: только пандусный и приямок.
- `монолитная_плита`: без стройзадания нет унифицированных чертежей.
- Supply-флоу на docxtpl — отдельная проверка плейсхолдеров при смене шаблонов.
- Автовыбор типа договора — подсказка-дефолт (radio), выбор ручной.
- Ручные позиции типа «Прочее» — строка + оплата, без клауз. Это норма для доп. работ
  (шкаф, кабель, транспорт). Монтаж — выбирать тип «Монтаж» (иначе нет обязательств).
