**Как фиксировать находки:**
Все в `docs/manual_review_findings.md`. Формат:
2026-05-XX: КП для ООО "Название"
Сценарий: ВЕСТА-С-60-18 + фундамент + монтаж, V1 50/50
Что не так: описание проблемы
Приоритет: P1/P2/P3
**Что можно править сразу:** данные в JSON (менеджеры, опции, цены).
**Что НЕ трогать:** код в `src/`, шаблон `kp_template.docx`, тесты.
